# roman_cuts.com — Commissioning & science data

Cutout utilities for Roman WFI commissioning and science data accessed via the
**MAST archive** (cloud ASDF files, GWCS astrometry).

Install the extra dependencies before use:

```bash
pip install "roman-cuts[com]"
```
