    roman_cuts.com — Commissioning & science data

    Cutout utilities for Roman WFI commissioning and science data accessed via the MAST archive (cloud ASDF files, GWCS astrometry).

    Install the extra dependencies before use:

    pip install "roman-cuts[com]"

    Query

    query_mast_files 

    query_mast_files(
    program_id,
    detector,
    filter_name,
    file_type="l2",
    execution_plan=None,
    pass_num=None,
    segment=None,
    observation=None,
    visit=None,
    mission=None,
)

    Query the MAST archive for Roman WFI files at a specific sky field.

    Roman file names encode the full observation hierarchy as r{PPPPP}{CC}{AAA}{SSS}{OOO}{VVV}_{eeee}_{wfiss}_{filter}_{suffix}:

    ======= === ================================================================ Level Len Meaning ======= === ================================================================ Program 5 Observing program (program_id) ExecPlan 2 Execution plan within the program (execution_plan) Pass 3 Pass within the execution plan (pass_num); repeat visits of the same field across epochs share the same pass Segment 3 Segment within a pass (segment) Observ. 3 Observation within a segment (observation); this is the primary sky-field identifier — all exposures with the same observation number point to the same sky patch Visit 3 Visit (dither position) within an observation (visit) Exposure 4 Individual detector exposure ======= === ================================================================

    Parameters:

    Name Type Description Default
    program_id int

    Roman program (proposal) ID, e.g. 1054.

    		 required
    detector str or int

    WFI detector. Any of 'WFI05', 'wfi05', 5, '05' are accepted and normalised to 'WFI##'.

    		 required
    filter_name str

    Optical element, e.g. 'F146' or 'f106'. Case-insensitive.

    		 required
    file_type ``'l1'``, ``'l2'``, or ``'l4'``

    Data level:

    • 'l1' – uncalibrated ramps (_uncal.asdf)
    • 'l2' – calibrated rate images (_cal.asdf) (default)
    • 'l4' – source catalogs (_cat.parquet)
    		 'l2'
    execution_plan int

    Execution plan number within the program (CC in the filename).

    		 None
    pass_num int

    Pass number within the execution plan (AAA). Different passes of the same observation cover the same sky at different epochs.

    		 None
    segment int

    Segment number within the pass (SSS).

    		 None
    observation int

    Observation number within the segment (OOO). This is the key parameter for selecting a specific field: all exposures sharing the same observation number are co-pointed.

    		 None
    visit int

    Visit (dither position) within the observation (VVV). Omit to retrieve all dithers at the field; supply to pin a single dither.

    		 None
    mission `~astroquery.mast.MastMissions`

    Authenticated mission object. When None, one is created from the MAST_API_TOKEN environment variable.

    		 None

    Returns:

    Name Type Description
    products `~astropy.table.Table`

    MAST product table. Each row is one file; products['filename'] can be passed directly to make_cutout.

    Cutout extraction

    make_cutout 

    make_cutout(
    file_names,
    ra,
    dec,
    size=(10, 10),
    mission=None,
    verbose=False,
    lite=False,
    n_workers=8,
    backend="thread",
    strict=False,
)

    Create pixel cutout cubes for one or more targets from Roman WFI L2 ASDF files.

    The GWCS stored in each ASDF file maps (ra, dec) to detector pixel coordinates. Each cutout is extracted with ~astropy.nddata.Cutout2D (mode='partial'), which fills out-of-bounds pixels with NaN and handles coordinates near the detector edge gracefully. Targets that fall outside a file's footprint are kept as NaN entries.

    Files are processed in parallel (one task per file; every target is cut from a file opened once) and the results are sorted by mid_time.

    File access is dispatched by ~roman_cutouts.io._open_asdf, which auto-detects the execution platform (RRN, SMDC, standalone) via ~roman_cutouts.io._detect_platform. Supply mission to force the RRN/MAST path from any platform.

    Parameters:

    Name Type Description Default
    file_names str or list of str

    MAST product filenames (RRN), local/mounted-S3 paths (SMDC), plain local paths, or s3:// URIs.

    		 required
    ra float or sequence of float

    Right Ascension(s) of the cutout centre(s) in degrees (ICRS).

    		 required
    dec float or sequence of float

    Declination(s) of the cutout centre(s) in degrees (ICRS).

    		 required
    size int, tuple of int, or list

    Cutout size in pixels. An int gives a square cutout shared by all targets; a (ny, nx) tuple a shared rectangle; a list of ints or tuples gives one size per target (length one is broadcast).

    		 (10, 10)
    mission `~astroquery.mast.MastMissions`

    Authenticated mission object for RRN/MAST access. With backend="process" it is not shared; workers create their own from MAST_API_TOKEN.

    		 None
    verbose bool

    Print per-file pixel-coordinate messages when True.

    		 False
    lite bool

    Extract only the data plane (cube axis 0 has length 1).

    		 False
    n_workers int

    Number of parallel workers (capped at the number of files). 1 runs serially. Default 8.

    		 8
    backend ``'thread'`` | ``'process'``

    'thread' (default) suits the I/O-bound workload and is safe in Jupyter and the CLI. 'process' uses a spawn process pool.

    		 'thread'
    strict bool

    Re-raise per-file errors instead of logging them and returning NaN.

    		 False

    Returns:

    Name Type Description
    cutout_cubes list of ndarray

    One per target, shape (n_types, n_files, ny, nx) where the first axis is [data, err, dq, dumo] (n_types=4, or 1 if lite).
    metadatas list of `~pandas.DataFrame`

    One per target, n_files rows with exposure, observation and instrument columns, mid_time, ra_target, dec_target and Cutout2D geometry fields. The boolean in_bounds column is False for NaN entries (target outside the file's footprint, or the file failed) and True otherwise, including partial overlaps, which are NaN-padded.
    gwcsss list of list of `~astropy.wcs.wcsapi.HighLevelWCSWrapper`

    One per target, n_files sliced GWCS objects (None for NaN entries). gwcsss[t][k].world_to_pixel(SkyCoord(...)) returns pixel coordinates in the cutout frame.
    All outputs are sorted by ``mid_time``; entries with unknown time go last.
    A scalar *ra*/*dec* is one target, so each returned list has length 1.

    End-to-end pipeline: query MAST → extract cutouts → optionally save.

    Combines query_mast_files, make_cutout, and save_to_asdf into a single callable that works from an interactive session, an import in another script, or the CLI via roman-make-cutout.

    Observation hierarchy parameters (execution_plan … visit) are forwarded to query_mast_files; see that function's docstring for the full naming-convention table. Specifying observation is the minimum needed to pin a single field.

    Parameters:

    Name Type Description Default
    ra float or sequence of float

    ICRS coordinates of the cutout centre(s) (degrees).

    		 required
    dec float or sequence of float

    ICRS coordinates of the cutout centre(s) (degrees).

    		 required
    program_id int

    Roman program ID.

    		 required
    detector str or int

    WFI detector ('WFI05', 5, '05' …).

    		 required
    filter_name str

    Optical element ('F146', 'f106' …).

    		 required
    cutout_size int, tuple of int, or list

    Cutout size in pixels (square, (ny, nx), or one per target).

    		 required
    file_type ``'l1'`` | ``'l2'`` | ``'l4'``

    Data level. Default 'l2'.

    		 'l2'
    execution_plan int

    Execution plan within the program.

    		 None
    pass_num int

    Pass (epoch) within the execution plan.

    		 None
    segment int

    Segment within the pass.

    		 None
    observation int

    Observation number — primary sky-field identifier.

    		 None
    visit int

    Visit (dither position) within the observation.

    		 None
    max_files int

    Cap on the number of files sent to make_cutout.

    		 None
    output_path str

    Directory in which to write the output ASDF file. None skips saving.

    		 None
    mission `~astroquery.mast.MastMissions`

    Authenticated mission object; auto-created from MAST_API_TOKEN when None.

    		 None
    verbose bool

    Forward verbose flag to make_cutout.

    		 False
    n_workers int

    Parallel workers used by make_cutout. Default 8.

    		 8
    backend ``'thread'`` | ``'process'``

    Parallel backend used by make_cutout. Default 'thread'.

    		 'thread'

    Returns:

    Name Type Description
    cutout_cubes list of ndarray or None

    One cube per target, shape (4, n_files, ny, nx).
    metadatas list of `~pandas.DataFrame` or None
    gwcsss list of list or None

    All three are None when MAST returns no products.

    save_to_asdf 

    save_to_asdf(
    cutout_cube, metadata, gwcss, filename=None, n_workers=8
)

    Serialise cutout cubes, metadata, and sliced GWCS lists to ASDF files.

    One file is written per target. Pass the lists returned by make_cutout (N targets → N files) or the arrays of a single target. Multi-target saving writes concurrently using a thread pool.

    Parameters:

    Name Type Description Default
    cutout_cube ndarray or list of ndarray

    Per-target cube(s), shape (n_types, n_files, ny, nx) ([data, err, dq, dumo], or data only when n_types == 1) or (n_files, ny, nx). A bare array is treated as one target.

    		 required
    metadata `~pandas.DataFrame` or list of `~pandas.DataFrame`

    Per-exposure metadata as returned by make_cutout.

    		 required
    gwcss list or list of list

    Per-cutout sliced GWCS objects (one list per target when cutout_cube is a list).

    		 required
    filename str or list of str

    Output file path(s) (*.asdf). With N > 1 targets it must be a list of length N. When None, each file is written to the current directory as cutouts_{pid}_{detector}_{filter}_{ra:.6f}_{dec:.6f}.asdf, with pid parsed from the leading PPPPP of the observation_id metadata column (PPPPPCCAAASSSOOOVVV), and detector (detector), filter (optical_element) and coordinates (ra_target, dec_target) also taken from the metadata. Missing values are written as unknown.

    		 None
    n_workers int

    Number of concurrent threads for writing ASDF files. Default 8.

    		 8

    Returns:

    Type Description
    list of str

    The paths written, one per target.
